## A. Any BG / no BG — menu + threat readout

1. **REL-1 options menu** — right-click the Titan bar button:
   - ✅ New **Sound alerts** checkbox (off by default) and a **Callout channel**
     radio group: Auto / Instance-BG / Raid / Party / Say. Auto is selected.
   - Set channel = **Say**. Fire any callout (open panel, click a grid cell).
     ✅ It goes to `/say`.
   - Set channel = **Raid** while solo/in a party (not a raid). Fire a callout.
     ✅ It still routes sensibly (falls back to Auto — never silently lost).
   - Reset channel = **Auto** when done.
2. **CMD-8 `/bgthreat`** (in a BG, after some combat): type `/bgthreat`.
   - ✅ Prints a local KILL/CC line built from real CLEU damage (+ healers).
   - Early match, before you've damaged anyone: ✅ KILL list still names enemies
     by **killing blows** (cold-start fallback), or a graceful "no data yet".
   - `/bgthreat announce` ✅ sends the threat call to BG chat (unchanged CMD-6).
